# 🚀 Página de Tributo: Legião Urbana

## 📌 Sobre o projeto
Este projeto é uma página web desenvolvida como tributo à banda **Legião Urbana**, um dos maiores nomes do rock brasileiro.  
A página apresenta informações sobre a história da banda, curiosidades, citações marcantes e imagens de destaque.  
Foi desenvolvido para fins educacionais e de portfólio.

________________________________________
🎯 Objetivo  
Criar uma página web informativa e estilizada que homenageia a banda Legião Urbana, destacando sua importância cultural e musical no Brasil.  

________________________________________
✨ Funcionalidades  
- Exibição de biografia da banda  
- Imagens de destaque com legendas  
- Citações de Renato Russo e músicas da banda  
- Lista de curiosidades sobre a Legião Urbana  
- Link para mais informações na Wikipédia  

________________________________________
🛠️ Tecnologias utilizadas  
- **HTML5** para estruturação da página  
- **CSS3** para estilização e layout responsivo  

________________________________________
📂 Estrutura do projeto  
```
├── index.html        # Página principal
├── styles.css        # Estilos da aplicação
├── img/              # Imagens utilizadas no projeto
└── README.md         # Documentação do projeto
```
